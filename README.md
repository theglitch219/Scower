# Scower

Full-stack marketplace for human intelligence.

## Stack
- Node.js + Express
- PostgreSQL
- React-style browser UI served by Express
- JWT authentication
- bcrypt password hashing

## Render
Create a Render Web Service from this repo. The included `render.yaml` can create the web service and Postgres database together.

Required environment:
- `DATABASE_URL` (Render provides this when using the Blueprint)
- `JWT_SECRET` (generated by Render)

The current payout record is database-backed and marked `pending`; real x402 + Algorand settlement is the next payment integration layer. No fake blockchain transaction is claimed.
